Политика конфиденциальности

Дата вступления в силу: 13 ноября 2026 г.

1. Общие положения

Настоящая Политика конфиденциальности описывает, как веб-приложение SIZ Tracker обрабатывает данные пользователей.

2. Какие данные собираются

Приложение хранит только следующие данные локально на устройстве пользователя (в IndexedDB браузера):

  • Информация о СИЗ: название средства индивидуальной защиты, инвентарный номер, дата следующей проверки
  • Настройки приложения: предпочитаемый язык, время ежедневной проверки, количество дней для предупреждений, выбранный звук уведомлений
  • Статусы СИЗ: отметки о сдаче на проверку, отложенные напоминания

3. Как данные используются

Все данные используются исключительно для:

  • Отображения списка СИЗ и их сроков проверки
  • Показа уведомлений о приближении сроков

4. Передача данных третьим лицам

Реестр СИЗ никуда не передаётся.

  • Нет аналитики и рекламных сетей
  • Если включён опциональный push-сервис, на сервер передаются только: push-подписка браузера, желаемое время проверки и метка времени следующего напоминания (без названий, номеров и дат СИЗ)
  • Уведомления формируются локально на устройстве

5. Хранение данных

  • Все данные хранятся только на устройстве пользователя в хранилище браузера (IndexedDB)
  • Данные не синхронизируются с облаком
  • Очистка данных сайта в браузере удаляет базу — рекомендуется периодически делать экспорт

6. Экспорт и импорт данных

Пользователь может:

  • Экспортировать свои данные в JSON-файл для резервного копирования
  • Импортировать данные из ранее созданного файла (формат совместим с Android-версией)
  • Удалить все данные через настройки приложения

7. Разрешения устройства

Приложение запрашивает следующие разрешения браузера:

  • Уведомления — для напоминаний о сроках проверки
  • Фоновая синхронизация (Periodic Background Sync) — для проверки сроков при закрытом сайте (только установленное PWA)
  • Вибрация — для сигналов в оповещении

8. Безопасность

  • Данные доступны только самому сайту (same-origin)
  • Для push-сообщений используется VAPID-аутентификация; полезная нагрузка не передаётся

9. Изменения в политике

Мы можем обновлять эту политику. Актуальная версия всегда доступна внутри приложения.
