# Сайт приложений dz529770-a11y

Публичный сайт с официальными страницами приложений, помощью, историями обновлений и политиками конфиденциальности. Исходный код Android-приложений хранится отдельно в приватных репозиториях.

## Как добавить приложение

1. Создать файл `_apps/app-slug.md` по образцу `_apps/krutanem.md`.
2. Добавить страницы `privacy.md`, `support.md` и `changelog.md` с постоянными адресами в `apps/app-slug/`.
3. Положить логотип и изображения в `assets/images/apps/app-slug/`.
4. Указать порядок карточки в поле `order` — приложение появится на главной автоматически.

В именах папок и постоянных адресах используются латинские буквы, цифры и дефисы. Номера версий не добавляются в URL документов.

## Публикация

Сайт собирается встроенным Jekyll на GitHub Pages из ветки `main`, каталог `/ (root)`.

## Безопасность

В этот репозиторий нельзя добавлять исходный код приложений, APK/AAB, ключи подписи, пароли, токены, локальные конфигурации и другие секреты.
